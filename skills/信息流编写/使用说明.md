# 信息流编写

调用：`-信息流编写`，也支持 `信息流编写`、`$信息流编写`。单独输入显示中文菜单，附任务时直接执行。

用途与范围：为全屋定制、家居、装修、建材等本地服务品牌采集需求、整理 brief、编写和优化抖音信息流获客脚本。

输入：客户资料、已填写调查清单、brief 或待修改文案。没有资料可先选择需求采集；预填品牌仅为示例。

流程：需求采集 → brief 确认 → 3 条样稿校准 → 补齐脚本（默认 15 条）→ 文案自检与 HTML 拼接文档交付。

输出：当前工作区 outputs/ 下的需求文档、脚本文档；简短结果可直接在聊天交付。HTML 含场景、三段口播、拍摄提示、待确认项及复制按钮。

安装：将本目录完整复制到本机 Codex 技能目录，保留 references、assets 和 agents；上传到 GitHub 本身不会自动安装。

验证与限制：已检查压缩包资源齐全、相对引用及中文触发入口。全局发现与新聊天调用以客户端加载测试为准；不保证广告审核、法律合规或投放效果。

公开仓库版本已移除原附件中的具体客户预填数据，表单为空白通用版。本机安装保留用户提供的原始示例。
