# 文案产出规则（通用模板 · 固定段落）

## 一句话公式

**城市业主痛点钩子（前 3 秒）→ 出镜人 IP 口语讲 3–4 个实力点（中间）→ 私信留资（结尾）**

## 三段式结构

| 段落 | 时长 | 任务 | 写法 |
|------|------|------|------|
| 开头 · 钩子 | 0–3 秒 | 点名人群＋戳一个痛点，把人留住 | 一句说完、不绕。点名「城市＋装修业主」，痛点从池子里选一个。 |
| 中间 · 买点阐述 | 22–35 秒 | 品牌背书＋产品卖点，把痛点解开 | 完整叙述、不精简，含 3–4 个实力点（只用客户确认的素材），末句自然引到结尾动作。 |
| 结尾 · 私信引导 | 3–5 秒 | 留资动作 | 只说站内「私信＋关键词」，动作按场景对应。 |

整条 35–48 秒；若投流 3 秒完播掉得快，可将中间段压成 2 个实力点做短版对照，完整版转主页自然发布。

## 钩子痛点池

怕买贵了 / 怕质量没保障 / 怕设计不好看 / 怕售后没保障（对应价格 / 品质 / 颜值 / 服务四类）。每条钩子只戳一个，别贪多。

## 三场景映射（痛点 → 拍摄地 → 结尾动作）

| 客户在意 | 拍摄场景 | 结尾动作（示例，按客户 brief 替换） |
|----------|----------|-------------------------------------|
| 价格 / 怕买贵 | 工厂（产线、报价单） | 私信「报价」领报价清单 · 私信「看厂」预约到厂参观 |
| 售后 / 品质 | 展厅（工艺细节、资质证书） | 私信「量尺」预约量尺 · 私信「方案」领设计方案 |
| 颜值 / 落地效果 | 样板间（实景、配色、案例图册） | 私信「看样」预约看样板间 · 私信「案例」查落地案例图册 |

映射逻辑：痛点决定内容线，拍摄地按客户实际场地填，结尾动作与该场景的转化目标对应。

## 调性要求（活人感 · 去 AI 味）

- **活人感**：用出镜人的口气——「说实话」「我跟你说」「这事我见太多了」「跑不了」「顺手」「我劝你」这类词；有停顿、有语气，不追求对仗。
- **不机械**：不套「城市XX的业主，怕XX？」的统一模板；每条句式错开；同一主张的多条钩子用不同口吻（自述 / 劝阻 / 算账 / 鉴别 / 复盘等），避免开头逐字一致被判创意重复、互相抢量。
- **小白能听懂，又显专业**：把工艺讲成人话——封边＝「摸上去平不平」，导轨＝「推起来晃不晃」，收口＝「贴墙那道缝收得齐不齐」；专业名词（产线名、认证名）点到为止，不堆术语。
- **点品牌与 IP**：每条文案点名品牌；出镜人自称自然带出（不必每条硬塞）；用从业年限、真实经历建立信任，不靠形容词自夸。

## 合规红线（交付前逐条扫描）

1. **极限词 / 绝对化**：不用「最、第一、唯一、首选、100%、全网、绝对、顶级、国家级」。
2. **价格**：只说「工厂价 / 按配置拆开 / 一款 XX 一平的」；不承诺具体金额、不说最低价、口播不说「引流款」「出厂价甩卖」「省一半」。
3. **环保 / 功效**：只说「认证名 + 检测报告可查」；不说零甲醛 / 无醛 / 绝对环保 / 母婴级。
4. **服务承诺**：只讲流程动作（量尺复尺、一套自己人、留记录）；不说终身保修 / 包满意 / 保证不返工 / 无效退款。
5. **导流**：只站内「私信＋关键词」；不出现加微信 / 留电话 / 扫码 / 点击下方链接。
6. **「免费」**：按客户需求保留；卡审替换说法备好——「领一份 / 安排 / 升级不加钱」。
7. **数字与凭据**：年限、面积、产线数、品牌名、认证须有凭据且与画面一致；无凭据的数量宣称（多少家案例、多少块色板）不上字幕；客户发来的原文若含此类宣称，保留原文但列入「待确认项」提示。

## 交付格式

- 拼接文档（HTML 表格）：序号 / 场景 / 开头 / 中间 / 结尾 五列；每行三段完整可拍。
- 附：拍摄提示（一句一个画面；凡提「源头工厂/工厂价」3 秒内切实拍；工艺给「手在动」的镜头；客户信息打码）＋ 待客户确认项清单。
- 提供一键复制纯文案功能；纯文案格式：【序号 场景】开头｜中间｜结尾。
- 分组配色区分三场景；打印友好。

## 产出流程自检

1. 每条三段齐全？开头只戳一个痛点？中间 3–4 个实力点且全部来自 brief 素材库？
2. 每条点名品牌？出镜人自称自然不硬塞？句式彼此错开？
3. 禁用词扫描零命中？「免费」类是否附了替换说法？
4. 无凭据数量是否已移入待确认项？
